# Jarvis AI Voice Assistant 🤖

An AI-powered Voice Assistant built using Python, SpeechRecognition, and OpenAI API integration.  
This assistant can recognize voice commands, generate intelligent responses, play music, fetch news headlines, and automate basic web tasks.

---

# 🚀 Features

- 🎤 Voice Recognition and Speech Input
- 🤖 AI-powered Response Generation
- 📰 Latest News Headlines Integration
- 🎵 Music Playback Control
- 🌐 Web Automation Commands
- ⚡ Lightweight and Fast Python Implementation

---

# 🛠️ Tech Stack

- Python
- SpeechRecognition
- OpenAI API
- NewsAPI
- PyAudio
- pyttsx3
